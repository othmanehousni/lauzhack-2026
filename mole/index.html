The desktop app starts a VM, the agent desktop, and shares only that window in the call. The agent opens decks, files and sites there, never on your own desktop, and the mole sits on your side of the screen, outside the shared frame.

On the phone

It follows you when you walk. Stand up and walk the room. Past three metres from the laptop, the phone's microphone takes the lead, so the mole still hears you and keeps the screen in step with the talk.

0.4 m

When it hesitates, it asks. If two documents fit what you said, the phone buzzes and the mole holds both up. Tap one or say its number. Nothing is shared until you pick.

Under the hood

One codebase. Kotlin Multiplatform shares the agent, built on Koog, between the desktop app and the Android companion.

Nothing leaves the room. EmbeddingGemma embeds each sentence on the device, and a Gemma model fine-tuned on meeting talk decides what to show.

A stage of its own. The agent desktop holds the decks, files and browser the agent drives. Your desktop stays as you left it.

Twice a second, a coroutine asks the agent whether there is anything to do. It acted. It asked you.

// commonMain: the same loop runs on the laptop and on the phone
flow {
    while (true) {
        emit(agent.anythingToDo(heard.value, onScreen.value))
        delay(500.milliseconds)
    }
}.collect { move ->
    when (move) {
        is Move.Show -> agentDesktop.show(move.target)
        is Move.Ask -> phone.buzz().ask(move.options)
        Move.Nothing -> Unit
    }
}
